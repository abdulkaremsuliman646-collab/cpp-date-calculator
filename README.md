# C++ Date Calculator

A practical C++ date management project that provides useful date and calendar calculations.

The project was built as part of my journey in learning C++ programming and focuses on applying fundamental programming concepts through a real-world date calculation problem.

---

## 🚀 Features

- Determine the day of the week for a given date.
- Check whether a date is the end of the week.
- Determine whether a date falls on a weekend.
- Determine whether a date is a business day.
- Calculate the number of days remaining until:
  - The end of the week.
  - The end of the month.
  - The end of the year.
- Handle leap years correctly.
- Calculate the number of days in a given month.
- Calculate the total number of days in a year.
- Demonstrate C++ Function Overloading.
- Use structures to represent dates.
- Organize the program into reusable functions.
